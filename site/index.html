See it work

The overlay, in four steps. Click anything.

Click Record. Use the app.

flowtape logs the current page, then every click, field value, form submit and client-side navigation.

  • Clicks inside the overlay are ignored.
  • Typing is debounced. Each field records its final value once.
  • The recording survives reloads in the same tab.

    Check what should be true.

    While you record, click Assert, choose a check, then click an element. The app never receives that click.

    • Text: the element is visible and shows its current text.
    • Count: how many elements match one of the rows.
    • Gone: the element leaves the page after the next action.
    • Esc or Cancel stops picking.

    Session history

    A log of what you did. Off until you switch it on.

    One JSONL file per browser tab, appended every second. Never turned into a named flow. Use Record for that.

    • Navigations, clicks, field values, form submits and uncaught errors.
    • Errors keep a scrubbed message, file, line and column. No stack.
    • No network capture: no request bodies, cookies or Authorization headers.
    • Gitignored: **/.flowtape/history/

    Redaction and local-first

    Redacted before it is stored

    Redaction runs in the browser, on the server before files are written, and over the final Markdown. Session history gets the first two.

    • Password fields never store a value, only its length.
    • data-flowtape-mask records every field inside type-only.
    • Allowlist mode for apps that handle personal data.
    • Pattern scrub covers tokens, JWTs, NHS numbers, emails, UK postcodes and mobiles.
    • No account
    • No cloud
    • No extension
    • No network capture

    The pattern scrub is a safety net, not a guarantee. Review a flow before you commit it.

    Everything else

    Small facts from the README.

    Vite and Next.js

    A Vite plugin, or route handlers for the Next.js App and Pages Routers.

    Assertions

    Text, Count and Gone checks become Check: steps in the prompt.

    e2e export

    A draft test for the e2e runner. Exact steps, no model, no API key.

    Replay scripts

    Record and replay from the CLI with Playwright, an optional peer dependency.

    Survives reloads

    Redacted events live in sessionStorage until the tab closes or you click Clear.

    Allowlist mode

    data-flowtape-allowlist records fields type-only and drops element text.

    Audit

    flowtape audit scans saved files for anything that still looks sensitive.

    Dev only

    The middleware runs under vite dev or next dev. The overlay is off in production.

    Add it to your app

    Render the overlay behind import.meta.env.DEV to keep it out of the production bundle.

    1. Install the package.

    Terminal
    npm install -D @vvedantb/flowtape

    2. Add the plugin.

    vite.config.ts
    import react from '@vitejs/plugin-react';
import { flowtape } from '@vvedantb/flowtape/vite';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [flowtape(), react()],
});

    3. Mount the overlay once.

    main.tsx
    import { FlowtapeOverlay } from '@vvedantb/flowtape';

createRoot(root).render(
  <>
    <App />
    <FlowtapeOverlay />
  </>,
);

    1. Install the package.

    Terminal
    npm install -D @vvedantb/flowtape

    2. Add the route (App Router).

    app/api/flowtape/[...path]/route.ts
    import { flowtapeRouteHandlers } from '@vvedantb/flowtape/next';

export const { GET, POST } = flowtapeRouteHandlers();

    3. Render the overlay in the layout.

    app/layout.tsx
    import { FlowtapeOverlay } from '@vvedantb/flowtape/next/client';

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        {children}
        {process.env.NODE_ENV === 'development' && <FlowtapeOverlay />}
      </body>
    </html>
  );
}

    Next.js uses /api/flowtape, not /__flowtape. Pages Router and handler options are in the README.
